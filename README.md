# ZYCLOPS — $ZYCL

One eye. Zero visibility. A cyclops memecoin on Zcash, live on [SHLD.fun](https://shld.fun/coin?a=2b3e27cd7b740a48a9036e20be3c40a8a814cc6e59c237a3db03203a6a398994).

Static landing page. No build step.

## Local

```bash
python3 -m http.server 4173
```

Open [http://localhost:4173](http://localhost:4173).

## Deploy

GitHub Pages, Netlify, or Cloudflare Pages from this folder. Point the site to `index.html`.

If you have a domain, add a `CNAME` file with that host.
