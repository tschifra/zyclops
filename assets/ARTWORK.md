# ZYCLOPS modern Solana website artwork

All displayed artwork uses the owner's approved modern ZYCLOPS identity: charcoal face, one ivory/gold eye, solid gold brow, short beard and black hood.

The hero is the approved reference portrait. The logo, favicon and downloadable transparent PNG derive from the approved modern coin badge. Scene illustrations, reaction portraits and meme posters were generated with the built-in image generation tool using that same portrait as the identity reference, then mechanically resized and compressed for delivery.

The shared collection's exact prompts and reference are in `/media-vault/meta/prompts.json` and `/media-vault/brand/zyclops-mascot-reference-v10.png`. The homepage's versioned delivery paths avoid stale cached images.

No animation files are shipped. Page movement is limited to CSS and respects reduced-motion preferences.
